# C-Flex 제품 기준선과 경쟁사 비교

검토일: 2026-10-11. 내부 개발·검수 문서. 경쟁사와 동등한 성능을 인증하는 문서가 아니다.

## 제품 방향

목표는 전문 FMS/DCIM의 기본 기능을 갖추고, 현대 내부 Probe/FMS와 외부 RingOn 매니지드 서비스 플랫폼을 연결하여 문의·장애 처리의 품질과 비용을 개선하는 것이다. AI는 반복되는 P3/P4 업무의 분류·조회·설명·답변·보고서 작성을 돕는다. P1/P2, 위험한 변경, 근거 부족, 고객의 상담원 요청은 담당자에게 인계한다. 낮은 우선순위로 접수됐더라도 영향이 크면 승격한다.

Schneider는 이미 AI·전문가·원격 모니터링을 결합한 서비스를 소개한다[S5]. Sunbird Power IQ에도 AI 기반 전원 부하 이동 탐지가 명시되어 있다[S2]. 따라서 'AI 최초', '기존 업체는 모니터링만 제공' 같은 주장은 사용하지 않는다. 우리의 차별화 가설은 **제조사에 걸친 FMS·IT·UC 지원, 고객별 운영 지식, 문의부터 해결까지 이어지는 서비스, 검증 가능한 처리 비용 절감**이다. 실제 우위는 비교 시험과 고객 운영 지표로 입증한다.

## 기능 동등성 판정 규칙

1. 각 계약 요구를 위 ID와 연결한다. 계약상 필수 항목이 미구현이면 운영 준비 완료로 판정하지 않는다. 향후 로드맵으로 조용히 넘기지 않는다.
2. 장비 지원 단위는 제조사 하나가 아니라 **모델 + 관리 카드 + 펌웨어 + 프로파일 버전**이다. 필수 지표, 알람, 복구, 읽기/쓰기 권한을 분리해 기록한다.
3. 진행 단계는 요구 정의 → 코드 → 시뮬레이터 → 실장비 → 현장 검수 → 운영 관측이다. 화면이나 코드의 존재만으로 완료 처리하지 않는다.
4. 미지원·미수집·오래된 데이터는 정상으로 집계하지 않는다. 시험에서 일부만 수집되면 부분 지원으로 남긴다.
5. 기능 동등성, 성능, 가용성, 보안, 운영 지원을 별도 평가한다. 기능 숫자가 같다고 동일 품질이 되는 것은 아니다.
6. 경쟁사 비교는 실제 제안 제품·버전·라이선스·서비스 범위를 고정한 뒤 검증한다. 공개 마케팅 자료는 요구 발굴의 출발점이다.

| 고객 경험 | 재문의·재접수·만족도·고객이 요청한 사람 연결 | 자동화율을 위해 사람 연결을 막지 않음 |
| 운영 비용 | 사람·온콜·클라우드·AI·채널·현장 출동의 월 총비용 | 특정 인원 감축이나 절감률을 실측 전에 약속하지 않음 |

목표 수치는 계약과 초기 운영 자료를 보고 정한다. 우선 과거 티켓으로 평가하고, 실제 운영에서는 AI가 제안만 하는 관찰 기간을 거친 뒤 검증된 P3/P4 유형부터 자동 응답을 켠다. P1/P2의 탐지·호출·대응 인력은 별도로 확보한다.

## 개발·검수 순서

- 첫 연결: 현대 계약 장비 목록을 모델별로 분류 → 공식 MIB/레지스터 맵 → 읽기 전용 수집 → 장비 화면 대조 → 로컬 FMS 표시.
- 첫 서비스: Probe 이벤트 → 클라우드 수신·중복 제거 → 영향·우선순위 판단 → 담당자/고객 통지 → SLA·해결 증거. 계약에서 약속한 채널부터 실제 시험.
- 첫 자동화: 반복 문의 지식화 → AI 근거·답변 검수 → 허용한 유형 자동 처리 → 재접수와 사람 작업시간 측정.
- 확장: 위 목록의 미완료 항목을 계약 우선순위로 개발하되, 전체 기준선에서 삭제하지 않는다. 용량 계획·고급 예측·전면 모델 지원은 별도 검증 과제로 유지한다.
