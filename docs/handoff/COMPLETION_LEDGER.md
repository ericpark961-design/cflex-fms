## 실제 연결이 0 인 이유 — 네 가지

1. **포털 mTLS 미개방.** `/api/v1/*` 7개가 구현돼 있으나 `mtls_ingress_not_activated`
   503. nginx `ssl_verify_client` 와 발급 CA 가 서버 담당 몫이다.
2. **발급 CA 없음.** 노드 인증서를 만들 수 없다.
3. **`apps/console` 이 어디에도 배포돼 있지 않다.** `fms.runless.co.uk`(VM1,
   172.172.161.236)에는 다른 C-Flex 프론트엔드가 떠 있고 `/healthz` 까지 HTML 을
   준다. 배치안이 먼저 필요하다 — 기존 화면을 교체하지 않는다.
4. **운영 서버 변경 금지 + SSH 차단.** 이 세션에서 배포를 수행할 수 없다.
